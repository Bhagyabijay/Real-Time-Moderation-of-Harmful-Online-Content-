# Real-Time-Moderation-of-Harmful-Online-Content

AI for Digital Well-Being: Real-Time Moderation of Harmful Online Content

# About the Project
This research project explores the use of Natural Language Processing (NLP) and machine learning to detect and classify harmful online text for real-time content moderation.

# Objective
To develop a real-time framework for identifying harmful online content using text preprocessing, feature extraction, and machine learning classification techniques.

# Technologies Used
- Python
- Natural Language Processing (NLP)
- TF-IDF (Term Frequency–Inverse Document Frequency)
- Random Forest
- Support Vector Machine (SVM)
- XGBoost

# Methodology
1. Preprocessed and prepared text data for analysis.
2. Extracted textual features using TF-IDF.
3. Trained and evaluated Random Forest, SVM, and XGBoost models.
4. Evaluated model performance using accuracy, F1-score, and prediction latency.

# Results
The tuned XGBoost model achieved the following results:
- Accuracy: 90%
- F1-score: 0.75
- Prediction latency: 0.004 seconds per sample
